## 🛠️ Technology Stack
This project is built using vanilla technologies to guarantee high performance, quick parsing, and lightweight rendering:
- **HTML5**: Semantic markup structuring with accessibility enhancements.
- **CSS3**: Variables for dynamic theming (Dark/Light modes), custom glassmorphism borders, glowing shadows, floating animations, and keyframes.
- **Bootstrap 5.3**: Grid frameworks, flexible layouts, and navigation responsive layouts.
- **JavaScript (ES6)**: Lag-inertia custom cursor, mouse-glow coordinate tracking, typing speed loop, intersection observer triggers, numbers animations, canvas particle drift, and form styling.
- **Font Awesome Icons**: Branding and interface representations.
- **Google Fonts**: Inter & Poppins typography.

## ✨ Features Included
1. **Interactive Glassmorphic Cards**: Features custom border highlights on mouse hover, reflecting mouse client coordinates.
2. **Light & Dark Mode**: Persistent toggle caching in client's LocalStorage.
3. **Optimized Particle Background**: Full viewport floating particle canvas with visibility observer pauses to minimize CPU drain.
4. **Lag-Chasing Custom Cursor**: Circular trailing ring using linear interpolation.
5. **Timeline Panels**: Premium vertical layouts for certificates and education metrics.
6. **Typing Animation loop**: Loops titles on hero sections.
7. **SEO Optimization**: Configured with meta descriptions, Open Graph cards, Twitter metadata, and structured JSON-LD schemas.

## 🔧 Setup & Local Deployment
To run this website locally:
1. Clone this repository to your local directory.
2. Open `index.html` directly in any web browser, or launch it with a local server package like Live Server (VS Code extension) or Node's `http-server`:
   ```bash
   # Using npm http-server
   npx http-server ./
   ```
3. Open `http://localhost:8080` in your browser.
